## Folder Plugin

+ Vietnamese: 

- Folder Plugin là một phần quan trọng trong hệ thống của Adaptive AI và Adaptive Intelligence Circle nói chung, khi nó sẽ giảm sự phân chia giữa thế giới trừu tượng (dữ liệu) và thế giới mà con người có thể cảm nhận được. Plugin cho phép tạo một cầu nối giữa các module trong các project con khác nhau nhưng vẫn đảm bảo vai trò của từng module trong hệ sinh thái mà không gây xung đột hay phân chia. Plugin được tạo ra để có thể kết nối với đa ngôn ngữ và chạy trên hệ điều hành mà vẫn đảm bảo được các nguyên tắc về bảo mật, tự phản vệ.

- Folder Plugin được thiết kế bởi các ngôn ngữ mềm dẻo và có tính tin cậy cao như Rust, Python và Lua -> có thể hoạt động trên các API của LLM hay NLP, thậm chí các mô hình học tăng cường. 

- Có một lưu ý rằng Plugin sẽ không nhằm phục vụ cho việc tăng tốc máy tính lượng tử vì nó có phần xa vời so với thực trạng hiện tại của module. Plugin làm giảm sự phụ thuộc vào việc train dữ liệu lớn nhưng vẫn đảm bảo hiệu suất và linh động. 

+ English: 

- Folder Plugin is an important part of the Adaptive AI system and Adaptive Intelligence Circle in general, as it will reduce the division between the abstract world (data) and the world that humans can perceive. Plugin allows to create a bridge between modules in different sub-projects but still ensures the role of each module in the ecosystem without causing conflicts or division. Plugin is created to be able to connect to multiple languages ​​and run on operating systems while still ensuring security and self-defense principles.

- Folder Plugin is designed by flexible and highly reliable languages ​​such as Rust, Python and Lua -> can work on LLM or NLP APIs, even reinforcement learning models.

- It should be noted that Plugin will not be intended to serve the purpose of accelerating quantum computers because it is somewhat far from the current state of the module. Plugin reduces the dependence on training large data but still ensures performance and flexibility.
