# Security Policy

## Reporting a Vulnerability
If you discover a security vulnerability, please email ndtribk@gmail.com with detailed information.

We will respond within 7 business days.

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |
| <1.0    | :x:                |

## Security Guidelines
- Do not publicly disclose security issues until fixed.
- Follow the principle of least privilege when contributing code.
